# Player view-pitch writer

`Player+0x3430` is maintained by the Player's secondary base at `+0x140`, so the earlier direct `+0x3430` scan missed its update. `00453D50` installs vtable `004E1C40` at that base; slot 0 is `00452570`. In this call, the subobject's `+0x32F0` aliases outer `Player+0x3430`.

`00452570` adds `STEER_PITCH`, wraps beyond ±360 degrees in 360-degree steps, then clamps symmetrically. Its mode value at the engine view object `+0x2C` selects ±20, ±40 or ±70 degrees (values 0, 1 or other). Player state 5 or the spectating byte raises a smaller cap to at least 45 degrees; the 70-degree cap stays 70. `PlayerManager` initializes fresh `TPlayerInfo+0x2C` to 1, and save/load uses that field as `DifficultyLevel`; this supports a ±40-degree fresh-profile default. A loaded profile or state 5/spectating can select a different effective limit.

Input setup maps `STEER_PITCH` to mouse axis 1; the mouse backend names that axis `MOUSE_Y`. `00439310` negates its raw backend value and multiplies by `004FF480`, which is `0.1`. The source path therefore adds `-0.1 degrees` per raw Y-axis unit at each Player update. No deadzone or frame-time multiplier occurs in this control wrapper. The raw backend getter returns its stored integer axis value. Static evidence does not establish that SDL relative-Y units have the same OS/backend scaling as the original game's stored axis values, and the native build does not load original player profiles or model the state-5/spectating exception.

Files in this directory preserve the previously temporary getter/wrapper exports, scalar words, xrefs, backend vtable and alias-access scan. Original `00452570` assembly and the direct-offset scan remain in the parent directories. The native event mapping applies the source sign and `0.1-degree` scale to SDL Y deltas and uses the source-backed ±40-degree fresh-profile default. SDL raw-unit equivalence, loaded-profile limits and the state-5/spectating exception are not implemented or verified. No debugger attach or live-input capture was used.
