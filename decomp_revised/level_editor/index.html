Controls & level notes

Select is the default camera mode: left-drag orbits, right-drag pans, and the wheel zooms. Click objects to select. Choose Move to drag an object across the ground plane; choose Place to add the selected asset. Placement height is editable. Arrow keys nudge 8 units; Shift+arrows nudge 32. Q/E rotates 15°. Delete removes an item; ⌘Z / ⇧⌘Z undo and redo. Esc returns to Select.

Positions use game units; Y is up. BSP brush models use extracted source geometry and textures. Survivors use extracted ACT geometry and textures in the bind pose; fires use extracted game sprites. Texture overrides apply to imported brushes or custom terrain. Roaming uses the authored roam command.

Custom maps target the native port. Imported brush collision currently uses a fitted box around source bounds. This does not export a retail Windows BSP.
