# Sikarugir/Wine runtime reference

The local Sikarugir/Wine wrapper is available to the project owner for future reference captures. Its game-specific overlay files, wrapper metadata, and bundled runtime are not included in this public folder. The retail EXE/DLL hashes match the pinned entries in `inputs/original/manifest.csv`.

Runtime observations through the wrapper must be tagged as Wine/Wineskin, the active graphics wrapper, and any patch or resolution changes. The wrapper selects a DirectX compatibility layer and applies a widescreen/FOV patch, so those settings do not define retail parity defaults.

Use overlays and wrapper metadata only to describe capture conditions. Keep captures separate from static code evidence and record the active wrapper, patch, resolution, and API translation layer.
