# Project tracker

This directory keeps the progress evidence that feeds the local dashboard.

- `functions.csv` is rebuilt from the fresh Ghidra exports. It includes body-bearing functions and external import stubs. Body-function totals are Ghidra's current boundaries, not a claim that every routine has been discovered.
- `binaries.csv`, `imports.csv`, `exports.csv`, and `sections.csv` hold PE module, section, and dependency facts from GNU `objdump`.
- `legacy_crosswalk.csv` joins prior indexed decompiler exports to current exact entry addresses. These are address-only joins: the prior index does not bind every export to a verified EXE hash. Legacy C-like exports are evidence artifacts, not recovered original source.
- `milestones.csv` tracks project outcomes separately from function counts.
- `function_reviews.csv` binds reviewed EXE functions to fresh pseudocode and behavior notes; these entries appear as `triaged` in the function atlas.
- `progress_history.csv` stores cumulative review snapshots for the dashboard time series.
- `genesis_api_crosswalk.csv` tracks selected EXE imports and their callers into Genesis.
- `evidence/genesis-boundary/` and `evidence/runtime-loop/` hold hash-pinned query outputs, pseudocode, and instruction evidence.
- `generated/` contains raw outputs produced by `tools/refresh_inventory.sh`.
- `summary.json` and `../dashboard/index.html` are regenerated by `tools/build_tracker.py`.

Stop the running GhidraMCP server before refreshing the project database. Run `tools/refresh_inventory.sh` after changing analysis inputs or Ghidra analysis. To export the current saved database without reanalyzing, run `tools/export_inventory.sh`. Restart the server afterward with `tools/ghidra-mcp/start_server.sh`. If startup reports that the project is locked, check `http://127.0.0.1:8089/check_connection` before trying another instance; one service may already be using the project. The current Codex MCP tool list may require trusting/reloading this project to expose the stdio bridge in-chat.


The public mirror intentionally omits retail files, extracted assets, and Ghidra databases. `inputs/original/manifest.csv` provides hashes for the local-only inputs. `legacy_crosswalk.csv` preserves provenance paths from a locally reviewed archive; its old export files are not duplicated here.
